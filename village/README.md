# 🏝️ 도란도란 섬

언제든 들러서 수다 떠는 작은 온라인 섬마을 (첫 번째 시제품).

## 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 열면 됩니다. 창을 두 개 열면 서로 보여요.

## 지금 되는 것
- 이름, 동물(고양이·강아지·토끼·곰), 색깔 골라서 입장
- 방향키/WASD 또는 화면 터치로 이동 (모바일 지원)
- 말풍선 채팅 (Enter로 말하기)
- 마을 게시판에 글 남기기 (서버에 저장)
- 꽃에 물 주기: 누가 물 줬는지 모두에게 알림, 하루 동안 꽃이 활짝 핌
- 화·금 밤 10시 "광장 수다 시간" 안내, 밤에는 마을이 어두워지고 창문에 불이 켜짐
