# 출시 준비 체크리스트 (이 순서대로)

여기 있는 일은 **Supabase·토스 화면에서 직접** 하셔야 해요. 앱 코드는 이미 준비돼 있어요.
막히면 그 화면을 캡처해서 보내 주세요. 자세한 설명은 각 줄 끝의 문서에 있어요.

> 이미 된 것: Supabase 프로젝트, `shares` 버킷, 공개 키(`config.js`), GitHub Pages 주소
> https://ohyeahhi.github.io/-/storybook/

---

## 1~2단계. 저장소·표 한 번에 (5분) — SQL Editor 에서 한 번만 Run
- [ ] Supabase → **SQL Editor** → **New query**
- [ ] `supabase/all-in-one.sql` 내용을 **통째로** 붙여 넣고 **Run**
  - 버킷 설정(10MB·허용 형식), 올리기 규칙(손주 답장 포함), 주문·보관·통계 표를 한 번에 만들어요
  - 여러 번 실행해도 괜찮아요. 전에 따로 실행한 파일이 있어도 그냥 다시 실행하면 돼요
- [ ] 맨 아래 결과 표 5줄이 모두 **✅** 인지 확인 (❌ 가 있으면 그 화면을 캡처해서 보내 주세요)
- [ ] 휴대폰으로 동화 하나 녹음 → **보내기** → 다른 휴대폰에서 링크 열어 듣기
  (자세히: `SETUP-공유.md` · 파일을 하나씩 실행하고 싶으면 `storage.sql` → `orders.sql` → `keeps.sql` → `events.sql`)

## 3단계. 결제 연결 (20분) — 그림책 주문·10년 보관 결제
- [ ] [토스페이먼츠 개발자센터](https://developers.tosspayments.com) 가입 → **API 개별 연동 키** 확인
- [ ] **Edge Functions → Deploy a new function → Via Editor**
  - 이름 `orders`, 코드 `supabase/functions/orders/index.ts` 붙여 넣고 Deploy
  - 함수 설정에서 **Verify JWT 끄기**
- [ ] **Edge Functions → Secrets**: `TOSS_SECRET_KEY` = `test_sk_…`
  ⚠️ 시크릿 키는 여기에만. 채팅·코드에 붙이지 마세요.
- [ ] 클라이언트 키 `test_ck_…` 를 저에게 보내 주시면 `config.js` 에 넣을게요 (공개해도 되는 키)
- [ ] 테스트 결제: 그림책 2권 + 선물 포장 → **78,000원**이 나오고 결제 완료 화면이 뜨는지
  (자세히: `SETUP-결제.md`)

## 4단계. 휴대폰에서 직접 확인 (30분) — 자동 테스트로는 못 보는 것
| 확인할 것 | 아이폰 사파리 | 안드로이드 크롬 | 카카오톡 안에서 |
|---|---|---|---|
| 처음 설정 → 동화 녹음 (마이크 허용) | ☐ | ☐ | ☐ (막히면 "다른 브라우저로 열기"가 떠야 해요) |
| 얼굴 켜고 녹화 → 들어보기 | ☐ | ☐ | – |
| 홈 "오늘의 추억 질문" → **말로 쓰기**로 대답 → 녹음 | ☐ | ☐ | – |
| 받은 링크에서 🌙 잠자리 모드 15분 → 까만 화면에서도 소리가 계속 나는지 | ☐ | ☐ | ☐ |
| 손주 쪽에서 다 듣고 → **답장 보내기** → 할머니 홈에 답장 카드 | ☐ | ☐ | ☐ |
| 보내기 → **다른 기종**에서 링크 열어 듣기 (안드로이드 녹음을 아이폰에서, 아이폰 녹음을 안드로이드에서) | ☐ | ☐ | ☐ |
| 내가 지은 이야기 → 그림 → 녹음 → 보내기 | ☐ | ☐ | – |
| 그림책 미리보기 → PDF로 저장 → QR을 카메라로 찍기 | ☐ | ☐ | – |
| 홈 화면에 추가 → 앱처럼 열기 | ☐ | ☐ | – |

이상한 화면이 나오면 캡처 + 어떤 휴대폰인지 알려 주세요.

## 5단계. 시범 운영 (가족 5~10곳 또는 복지관 1곳)

- [ ] 복지관이면 안내지 인쇄: `앱주소#/flyer/기관코드` (예: `#/flyer/mapo-welfare`)
- [ ] 제안서: 복지관 시범 운영 제안서 문서의 [이름]·[연락처] 채우기
- [ ] 부모님께 보내기: `앱주소#/about` 링크를 아는 가족에게

## 6단계. 1년이 되기 전에 — 보관 기간 정리
- [ ] Edge Function `cleanup` 배포 (Verify JWT 끄기) + Secret `CLEANUP_TOKEN` (아무도 모르는 긴 글자)
- [ ] 먼저 `{"dry": true}` 로 지울 목록만 확인 → **Integrations → Cron** 에 하루 한 번 등록
  (자세히: `SETUP-보관.md`)
