# 녹음 보관 기간 · 10년 보관 상품 켜기

| | 보관 기간 |
|---|---|
| 무료 | 링크를 만든 날부터 **1년** |
| 10년 보관 (9,900원, 한 번 결제) | 결제한 날부터 **10년** |
| 그림책 주문 | 그림책에 들어간 녹음도 결제한 날부터 **10년** (QR이 계속 열리게) |

- 무료 기간이 60일 안에 끝나면, 링크를 연 가족에게 "이 녹음은 ○월 ○일에 지워져요" 안내가 떠요.
- 손주 화면 끝에 "🔒 이 목소리 오래 간직하기"가 있어요. 주로 링크를 받은 부모(자녀)가 사요.
- 가격은 `pricing.js`(앱)와 `supabase/functions/orders/index.ts`(서버)에 있어요. 바꿀 때는 둘 다 바꿔요.

## 1. 표 만들기 (결제 설정을 마친 뒤)
Supabase → SQL Editor 에 `supabase/keeps.sql` 을 붙여 넣고 **Run**.
그 다음 orders 함수를 **다시 배포**해요 (보관 상품이 들어간 새 코드).

## 2. 기간 끝난 녹음 지우기 (cleanup 함수)
이 함수는 하루 한 번 세 가지를 정리해요: ① 보관 기간이 끝난 녹음 ② 공유 ID 모양이 아닌 곳에 올라온 파일 ③ 하루 넘게 결제되지 않은 주문 (이름·전화·주소가 남지 않게).
돈 내고 보관한 녹음은 keeps 표를 끝까지 읽어서 확인한 뒤에만 남은 기간을 계산해요.

1. Edge Functions → **Deploy a new function** → 이름 `cleanup` → `supabase/functions/cleanup/index.ts` 내용을 붙여 넣고 배포. **Verify JWT 는 꺼요.**
2. Edge Functions → **Secrets** 에 `CLEANUP_TOKEN` 을 추가해요. 값은 아무도 모르는 긴 글자 (예: 비밀번호 생성기로 만든 32자).
3. 먼저 **지우지 않고 목록만** 확인해요. 터미널이나 Supabase 의 함수 테스트 화면에서:
   - 헤더 `x-cleanup-token: <CLEANUP_TOKEN 값>`
   - 본문 `{"dry": true}`
   - 돌아온 `expired` 목록이 맞는지 봐요.
4. 맞으면 **Integrations → Cron** 에서 하루 한 번(예: 새벽 4시) 이 함수를 부르는 작업을 만들어요. 본문은 `{"dry": false}`, 헤더는 위와 같이.

> 처음 1년 동안은 지울 녹음이 없어서 2~4번은 나중에 해도 돼요. 다만 약관에 "1년 뒤 지워요"라고 적혀 있으니 1년이 되기 전에는 꼭 켜 주세요.
