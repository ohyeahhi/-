# 음성 안내 녹음 파일

녹음 화면의 "안내" 버튼은 이 폴더에 아래 파일이 있으면 **사람 목소리 파일**을 틀고,
없으면 휴대폰의 음성 합성(가장 자연스러운 한국어 목소리를 골라요)으로 읽어 줘요.

| 파일 | 언제 | 읽을 글 |
|---|---|---|
| `intro-grandma.mp3` / `intro-grandpa.mp3` | 인사말 쪽 | 손주에게 하고 싶은 인사를 편하게 말씀해 주세요. 빨간 버튼을 누르면 녹음이 시작되고, 다 말씀하시면 버튼을 한 번 더 누르시면 돼요. |
| `page-grandma.mp3` / `page-grandpa.mp3` | 동화 쪽 | 화면의 글을 소리 내어 읽어 주세요. 빨간 버튼을 누르면 녹음이 시작되고, 다 읽으시면 버튼을 한 번 더 누르시면 돼요. |

- 할머니용·할아버지용을 같은 파일로 써도 돼요 (같은 녹음을 두 이름으로 복사).
- 휴대폰 녹음 앱으로 조용한 곳에서 또박또박, 조금 천천히 녹음하면 충분해요. mp3(또는 m4a를 mp3로 바꿔서)로 넣어 주세요.
- 더 매끄러운 목소리가 필요하면 네이버 클로바더빙·타입캐스트 같은 AI 성우 서비스로 만들어 넣어도 돼요 (상업 이용 조건 확인).
