# 들려줄게 (가칭)

할머니·할아버지가 **자기 목소리로 동화를 녹음**해서 손주에게 들려주는 웹앱이에요.

## 지금 되는 것 (시제품 v0.1)
- **처음 설정**: 할머니인지 할아버지인지, 손주 이름(선택)을 정해요
- **동화 3편**: 해님 달님, 토끼와 거북이, 금도끼 은도끼 (저작권이 끝난 이야기를 짧게 다시 썼어요)
- **쪽마다 녹음**: 큰 빨간 버튼으로 녹음하고, 들어보고, 다시 녹음할 수 있어요
  - 동화마다 첫 쪽은 손주에게 건네는 **인사말**이에요
  - 녹음하는 동안 소리 크기 막대와 시간이 보여요
  - "안내 듣기" 버튼을 누르면 사용법을 소리로 읽어줘요
- **손주 화면**: 그림과 글을 보며 녹음된 목소리를 들어요. 한 쪽이 끝나면 다음 쪽으로 저절로 넘어가요
- 카카오톡 안에서 열렸을 때 녹음이 막힐 수 있다는 안내와 "다른 브라우저로 열기" 버튼
- 다크 모드, 홈 화면에 앱처럼 추가(PWA), 한 번 열면 인터넷이 없어도 화면이 떠요

녹음은 **이 기기 안(IndexedDB)에만** 저장돼요. 서버는 아직 없어요.

## 실행하기
```bash
cd storybook
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
마이크는 `https` 주소나 `localhost`에서만 켜져요. 휴대폰으로 시험하려면 GitHub Pages나 Netlify 같은 곳에 올려서 https 주소로 열어주세요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 뼈대 |
| `app.js` | 화면 이동, 녹음, 재생 |
| `stories.js` | 동화 글 (여기에 추가하면 목록에 바로 나와요) |
| `db.js` | 녹음 파일 저장 (IndexedDB) |
| `styles.css` | 디자인 (토스·애플 스타일, 다크 모드) |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 추가와 오프라인 지원 |
