# 들려줄게 (가칭)

할머니·할아버지가 **자기 목소리로 동화를 녹음**해서 손주에게 들려주는 웹앱이에요.

## 지금 되는 것 (시제품 v0.9)
- **처음 설정**: 할머니인지 할아버지인지, 손주 이름(선택), **글씨 크기(보통·크게: 화면 전체 115%)** 를 정해요. 오른쪽 위 사람 모양 버튼으로 언제든 바꿔요
- **동화 19편, 편마다 10쪽**: 해님 달님, 토끼와 거북이, 금도끼 은도끼, 팥죽 할멈과 호랑이, 의좋은 형제, 젊어지는 샘물, 흥부와 놀부, 혹부리 영감, 해님과 바람, 개미와 베짱이, 양치기 소년, 빨간 모자, 아기 돼지 삼형제, 시골쥐와 서울쥐, 황금알을 낳는 닭, 토끼와 자라, 여우와 신 포도, 견우와 직녀, 콩쥐 팥쥐 (모두 저작권이 끝난 옛이야기를 직접 다시 쓴 글)
- **쪽마다 움직이는 그림**: 직접 그린 벡터 일러스트 191장(19편 × 10쪽 + 인사말). 호랑이 꼬리, 굴뚝 연기, 동아줄, 도깨비 방망이, 베짱이 바이올린 등이 살짝 움직여요. 캐릭터는 한 번씩만 정의돼 있어서 모든 쪽에서 똑같이 나와요 (`python3 tools/build_images.py`로 다시 만들기)
- **글꼴**: Pretendard를 앱 안에 넣어서 인터넷이 없어도 똑같이 보여요 (SIL 오픈 폰트 라이선스, `fonts/pretendard/LICENSE.txt`)
- **쪽마다 녹음**: 큰 빨간 버튼으로 녹음하고, 들어보고, 다시 녹음할 수 있어요
  - 동화마다 첫 쪽은 손주에게 건네는 **인사말**이에요
  - 녹음하는 동안 소리 크기 막대와 시간이 보여요
  - "안내 듣기" 버튼을 누르면 사용법을 소리로 읽어줘요
- **얼굴도 함께 담기 (켜고 끄기)**: 녹음 화면 위쪽 "얼굴" 버튼을 켜면 얼굴 영상과 목소리를 같이 녹화해요 (미리보기는 녹음 버튼 옆). 손주 화면에서는 그림을 가리지 않게 그림 아래, 글 옆에 영상통화처럼 나와요 (설정은 기억해요)
- **내가 지은 이야기**: 장면마다 글을 적으면(또는 "말로 쓰기") 글을 읽고 그림을 바로 조립해요. 누가(캐릭터 37가지: 사람·호랑이·토끼에 개구리·병아리·닭·오리·소·곰·여우·사슴·생쥐·원숭이·코끼리·부엉이까지)·어떤 감정(27가지 · 표현 240개: 기쁨·슬픔·외로움·실망·무서움·당황·놀람·화남·샘·걱정·궁금함·심심함·부끄러움·감동·사랑·고마움·뿌듯함·신남·안심·피곤함·배고픔·아픔·미안함·용기·평온·잠. 얼굴 14가지(웃음·보통·놀람·울음·잠·화남에 슬픔·걱정·하트 눈·신남·피곤·아픔·부끄러움·으쓱을 더했어요) + 머리 위 표시(비구름·느낌표·김·땀방울·소용돌이·말줄임표·하트·반짝이·불꽃…) + 몸짓(덜덜·깡충) + 하늘빛)·어떤 상황(100가지: 설날·추석·김장·운동회·캠핑·크리스마스·장날·입학·병원·자장가·꽃구경·모내기… 상황 하나로 배경·시간·날씨·소품·몸짓·분위기가 함께 바뀌어요. 표는 `scenes.js`)·무엇을(달리기·노래·춤·먹기·안기)·언제(낮·저녁·밤)·어디서(집·숲·들판·논·연못·바다·방·부엌)·날씨와 계절(비·눈·무지개·봄·가을)·물건 70가지쯤(과일 9·채소 8·먹을거리 11·장난감·탈것·살림살이…)을 그림에 넣어요. "사과나무에서 사과를 따 먹었다"면 과일이 열린 나무를 그리고, 먹는 장면이면 먹을거리를 손에 쥐어 줘요. "사과했어요"(잘못을 빎)·"배가 고파" 같은 뜻이 둘인 말은 걸러요 (새 부품은 `tools/parts3.py`). **인물 수**: 한 장면에 다섯까지 서고(넷 이상이면 두 줄로), "강아지 두 마리"·"돼지 삼형제"·"고양이들"·"쌍둥이"처럼 수를 말하면 그만큼 그려요. 아무도 안 나오면 풍경만 그리고, 장면마다 **인물 빼기** 버튼으로 글에 이름이 나와도 풍경만 그릴 수 있어요 (가족에게 보낸 링크에도 그대로 가요). 장면마다 **그림에 넣은 것**(누가·무엇·어디·언제·어떻게)을 꼬리표로 보여 주고, 빠진 게 있으면 "어디인지 적으면 배경이 바뀌어요"처럼 한 줄 도움말을 띄워요 "다른 그림"으로 다시 그리기, 고치기·지우기, 가족 공유도 돼요 (`composer.js`, `mystories.js`, 부품은 `img/parts.js`)
- **추억 질문 → 옛날 이야기 책**: 홈 맨 위 "💭 오늘의 추억 질문" 카드(어린 시절·학교·가족·젊은 날·엄마·아빠 이야기·손주에게 등 48가지, 하루 하나, "다른 질문" 가능)에 말로 대답하면 글에 맞는 그림이 그려지고 "할머니의 옛날 이야기" 한 장면으로 모여요(`#/memory`, 질문은 `memories.js`). 저장하면 바로 그 장면을 녹음할 수 있고, 녹음·보내기·그림책·주문은 직접 지은 이야기와 똑같이 돼요. 그림책과 듣기 화면에는 장면 위에 질문(Q.)이 함께 나와요. 10개가 모이면 책으로 만들자고 권해요 (최대 30개)
- **홈**: 동화를 **우리 옛이야기**(10편)와 **세계 명작**(9편)으로 나눠 보여 주고, 하다 만 녹음이 있으면 맨 위 **이어서 녹음하기** 카드로 남은 쪽부터 바로 이어가요
- **손주 화면**: 그림과 글을 보며 녹음된 목소리를 들어요. 한 쪽이 끝나면 다음 쪽으로 저절로 넘어가요
- **잠자리 모드**: 듣기 첫 화면에서 🌙 15분·30분을 고르면 화면이 밤 색으로 어두워지고, 그 시간 동안 동화를 처음부터 되풀이해 들려준 뒤 "잘 자요, 하은아"로 끝나요. "까만 화면으로 소리만 듣기"를 누르면 화면이 까매지고(누르면 다시 보여요), 되는 휴대폰에서는 화면이 꺼지지 않게 잡아 둬요 (Wake Lock). 고른 시간은 기억해요
- **재생이 안 될 때**: 손주 휴대폰이 녹음 형식을 못 읽거나 인터넷이 끊기면, 그 쪽은 안내를 띄우고 그림을 6초 보여 준 뒤 다음 쪽으로 넘어가요. 두 쪽 넘게 하나도 안 나오면 다른 브라우저로 열기(카톡)나 링크 복사를 권해요
- **가족에게 보내기**: 다 녹음하면 링크를 만들어 카톡·문자로 보내요. 받은 사람은 앱 설치나 가입 없이 링크만 눌러서 들어요
  - 다시 녹음한 쪽이 없으면 같은 링크를 다시 써요
  - 끝 화면의 "우리 가족도 만들어 보기"로 받은 가족이 새 사용자가 돼요
  - **우리 가족 책장 (사람별 존)**: 가족마다(할머니·삼촌·예림이모…) 보낼 때 자기 책장(`<책장ID>/s-1…30.json`, 할머니 휴대폰의 키로 서명)에 쌓여요. 아이 휴대폰은 열어 본 동화·책장 링크의 책장을 모두 기억해서 `#/family`에서 사람별 존으로 책꽂이처럼(책 등) 보여 주고, 처음 설정 없이 앱을 열면 여기로 와요. 새로 들어온 동화에는 "새" 표시가 붙어요. 홈의 "📚 가족 책장"에서 링크 보내기·미리 보기
  - **손주 답장**: 끝 화면의 "🎤 할머니께 답장 보내기"로 손주가 30초까지 목소리 답장을 보내요 (보호자 확인 체크 후). 할머니 홈 맨 위에 "하은이가 답장을 보냈어요" 카드가 뜨고 `#/replies`에서 모아 들어요. 파일은 `<공유ID>/reply-1…9` (목록 보기 없이 번호로 찾아요)
  - 서버 연결은 `SETUP-공유.md` 참고 (Supabase 무료 요금제)
- **그림책 만들기**: 동화 화면의 "📖 그림책으로 만들기" → A5 가로 그림책 미리보기(표지·인사말·쪽마다 그림+글+QR·뒤표지) → "PDF로 저장". QR 을 휴대폰 카메라로 찍으면 그 쪽부터 할머니 목소리(얼굴 영상)로 들어요 (`#/s/<공유ID>/<쪽>`)
- **그림책 주문·결제**: 주문서(받는 분·주소·권수·**선물 포장+카드**·동의). 값은 첫 권 39,000원, 두 번째 권부터 29,000원, 선물 포장은 권마다 5,000원 (`pricing.js`와 서버가 같은 규칙으로 계산) → 토스페이먼츠 결제창 → 서버에서 금액 확인 후 승인 (`pay.js`, `supabase/functions/orders`). 인쇄소용 화면 `#/print/<공유ID>`. 설정은 `SETUP-결제.md`
- **부모(자녀)용 소개 화면** `#/about`: 쓰는 법 3단계, 그림 예시, 그림책 안내, 자주 묻는 것. "부모님께 보내기"로 할머니·할아버지께 앱 링크를 카톡으로 보내요. 손주 화면 끝의 "우리 가족도 만들어 보기"도 여기로 와요 (처음 설정 없이 열려요)
- **약관·개인정보처리방침·환불 규정** (`#/policy/terms|privacy|refund`, 글은 `policies.js`): 홈 아래쪽과 주문서에서 열려요. 처음 서버에 올릴 때(보내기·QR·주문) 무엇이 올라가는지 보여 주고 **손주 보호자 동의**를 체크해야 올라가요. 출시 전에 `policies.js`의 `[상호]` 같은 사업자 정보를 채우고 법률 검토를 받아야 해요
- **녹음 보관과 10년 보관 상품**: 공유한 녹음은 1년 무료 보관, 끝나기 60일 전부터 듣는 화면에 안내가 떠요. 손주 화면 끝 "이 목소리 오래 간직하기"(`#/keep/<공유ID>`)에서 9,900원으로 10년 보관을 사요. 그림책을 사면 10년 보관이 함께 돼요. 기간이 끝난 녹음은 `cleanup` 함수가 지워요 (`SETUP-보관.md`)
- **가족 1년권** (`#/pass/<책장ID>`, 29,000원 · 자동 갱신 없음): 1년 동안 보내는 동화 모두 + 지금까지 책장에 보낸 동화와 책장을 10년 보관. 손주네가 책장 화면에서 선물로 살 수도 있어요. 새로 보낸 동화는 `pass_claim`으로 서버가 확인해서 보관을 올려요 (`passes` 표, `pricing.js`의 `PASS_PRICE`와 서버 값을 함께 바꿔요)
- **기관(복지관·경로당) 시범 운영**: `#/flyer/<기관코드>` 에서 큰 글씨 A4 안내지(QR 포함)를 인쇄해요. QR로 들어온 어르신의 사용 기록에는 기관 코드가 붙어서, `supabase/events.sql` 5번 질문으로 기관별 참여 결과(참여 인원·녹음·완성·가족 재생)를 뽑아요
- **시범 사용 통계**: 녹음·완성·보내기·가족이 듣기·주문 같은 사용 기록을 개인정보 없이 모아요 (`stats.js`, `supabase/events.sql`). 켜는 법과 서류용 숫자 뽑는 SQL은 `SETUP-통계.md`
- 카카오톡 안에서 열렸을 때 녹음이 막힐 수 있다는 안내와 "다른 브라우저로 열기" 버튼
- 다크 모드, 홈 화면에 앱처럼 추가(PWA), 한 번 열면 인터넷이 없어도 화면이 떠요
- **가족이 함께 만들기**
  - **이야기 릴레이** (`#/relay/<공유ID>`): 다 녹음한 지은 이야기에서 "🔗 이어 짓기 부탁하기" → 받은 가족이 다음 장면을 적고 녹음해서 이어 붙여요. 앞사람 녹음은 다시 올리지 않고 그 링크 파일을 가리켜요 (`manifest.pages[].from`)
  - **명절 모드**: 동화 화면 "🎉 명절 모드"를 켜면 녹음 화면에서 쪽마다 "누가 읽나요?"를 골라요. 손주 화면에 "🧔 큰삼촌이 읽어요"가 떠요

녹음은 **이 기기 안(IndexedDB)** 에 저장되고, "보내기"를 누를 때만 서버(Supabase Storage)에 올라가요.

> **출시 준비는 [`LAUNCH.md`](LAUNCH.md) 한 장에 순서대로 정리돼 있어요.**

## 실행하기
```bash
cd storybook
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
마이크는 `https` 주소나 `localhost`에서만 켜져요. 휴대폰으로 시험하려면 GitHub Pages나 Netlify 같은 곳에 올려서 https 주소로 열어주세요.

## 테스트
```bash
node tests/run.mjs          # 전체 (약 3분)
node tests/run.mjs book     # 이름에 book 이 들어간 것만
```
앱 서버와 가짜 Supabase·토스 서버(`tests/mock_supabase.py`)를 띄우고, 휴대폰 화면으로 녹음 → 보내기 → 가족이 듣기 → 그림책 주문·결제 → 보관 결제 → 재생 실패 → 약관·소개·기관 안내지까지 눌러 봐요. 마이크·카메라는 크롬의 가짜 장치를 써요. Python 3 와 Playwright(크로미움)가 필요해요 (`npm i -D playwright && npx playwright install chromium`).
고친 뒤에는 꼭 돌려서 모두 통과하는지 확인해 주세요. 실제 휴대폰(특히 아이폰 사파리) 확인은 따로 해야 해요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 뼈대 |
| `app.js` | 화면 이동, 녹음, 재생 |
| `stories.js` | 동화 글 (여기에 추가하면 목록에 바로 나와요) |
| `db.js` | 녹음 파일 저장 (IndexedDB) |
| `mystories.js`, `composer.js` | 내가 지은 이야기 저장, 글 → 그림 자동 조립 |
| `share.js`, `config.js` | 가족 공유 링크 (Supabase Storage에 올리기·받기) |
| `styles.css` | 디자인 (밝은 크림 + 꿀색 노랑, 다크 모드), 쪽 그림 배경과 움직임 |
| `img/`, `tools/` | 쪽 그림(SVG)과 그림 생성기: `draw_scenes.py`(그림체·처음 캐릭터), `parts2.py`(새 캐릭터), `build_images.py`(쪽별 장면) |
| `pay.js`, `supabase/` | 그림책 결제(토스페이먼츠)와 주문 서버(Edge Function), 주문 표 SQL |
| `stats.js` | 시범 사용 통계 (무작위 기기 번호, 개인정보 없음) |
| `policies.js` | 약관·개인정보처리방침·환불 규정, 사업자 정보 |
| `vendor/qrcode.js` | QR코드 만들기 (qrcode-generator, MIT) |
| `tests/` | 자동 테스트 (`run.mjs`, 가짜 서버 `mock_supabase.py`) |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 추가와 오프라인 지원 |
