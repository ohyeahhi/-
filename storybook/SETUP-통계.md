# 시범 사용 통계 켜기 (5분)

창업지원사업 서류에 넣을 숫자(몇 가족이 녹음했는지, 보낸 링크를 가족이 몇 번 들었는지, 일주일 뒤에도 다시 쓰는지)를 모아요.
이름·연락처·녹음 내용은 모으지 않고, 기기는 앱이 만든 무작위 번호로만 구분해요. (개인정보처리방침 ‘이용 통계’에 적혀 있어요)

## 1. 표 만들기
1. Supabase 대시보드 → 왼쪽 **SQL Editor** → **New query**
2. `supabase/events.sql` 내용을 **전부** 붙여 넣고 **Run** (예전에 실행했어도 다시 실행하면 새 기록 이름이 더해져요)
3. "Success. No rows returned" 가 나오면 끝이에요.

앱은 이미 `config.js` 의 Supabase 주소와 공개 키로 보내고 있어서 **앱 쪽은 고칠 게 없어요.**
표를 만들기 전에는 기록이 조용히 버려지고, 앱은 그대로 움직여요.

통계를 끄고 싶으면 `config.js` 에 `stats: false` 를 넣어요.

## 2. 숫자 보기
SQL Editor 에서 `supabase/events.sql` 아래쪽 주석에 있는 질문을 붙여 넣고 실행해요 (앞의 `-- ` 는 지우고).

| 질문 | 서류에 쓰는 말 |
|---|---|
| 1) 주마다 연 기기·녹음한 기기·완성한 동화·보낸 링크·링크 재생 | 주간 활성 사용자, 완성률 |
| 2) 링크 하나를 몇 번 들었나 | 가족 1곳당 평균 재생 횟수 |
| 3) 일주일 뒤에도 녹음한 비율 | 재사용률(리텐션) |
| 4) "우리 가족도 만들어 보기"·"부모님께 보내기" 수 | 입소문(바이럴) 지표 |
| 6) 끝까지 들은 링크 중 손주 답장이 온 비율 | 가족 반응률 (조부모가 다시 오는 이유) |

## 모으는 기록
| 이름 | 언제 |
|---|---|
| `open` | 앱을 연 날 (하루 한 번) |
| `start` | 처음 설정을 마쳤을 때 (할머니/할아버지, 손주 이름을 넣었는지 여부만) |
| `record` | 한 쪽을 녹음했을 때 (얼굴 영상인지) |
| `complete` | 동화 한 편을 끝까지 녹음했을 때 |
| `create` | 직접 지은 이야기를 저장했을 때 (장면 수) |
| `share` | 가족에게 보낼 링크를 만들었을 때 |
| `listen` / `listen_end` | 받은 가족이 듣기 시작 / 끝까지 들었을 때 |
| `invite` | 받은 가족이 "우리 가족도 만들어 보기"를 눌렀을 때 |
| `about` / `send_parents` | 소개 화면을 열었을 때 / "부모님께 보내기"를 눌렀을 때 |
| `book` / `order` / `paid` | 그림책 미리보기 / 결제 시작 / 결제 완료 (meta.kind: book · keep) |
| `keep_view` | "오래 간직하기" 화면을 열었을 때 |
| `reply` | 손주가 목소리 답장을 보냈을 때 |

1년이 지난 기록은 지워 주세요: `delete from public.events where at < now() - interval '1 year';`
